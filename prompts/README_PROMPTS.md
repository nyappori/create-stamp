# Prompt update notes

`01_big_jump.mp4` の確認結果を反映した共通プロンプトです。

追加したルール:
- 目は参照画像と同じ「黒い単純な楕円」に固定
- キラキラ目、ハイライト、アニメ目、星形目などを禁止
- 表情変化は許可するが、顔の基本デザイン変更は禁止
- 地面の影、接地影、ドロップシャドウを禁止
- 背景は完全に均一なグリーンを維持
- カメラ移動、ズーム、回転、揺れを禁止
- パーティクル、記号、エフェクト類を禁止

通常は `common_prompt.txt` と `actions.csv` の各 `action_prompt` をスクリプトが結合します。
`01_big_jump_full.txt` は大ジャンプを手動で再生成するときのコピペ用です。
